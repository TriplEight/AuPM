# Contributing

AuPM takes issues only. The project does not accept pull requests from outside contributors.
A pull request from an outside contributor is closed without review.

## Which form to use

Open an issue with one of the forms in the issue tracker.

- **Bug report.** Use it for a defect in the proxy, the CLI, the MCP server, the GitHub Action
  or the contract. State the version, the steps, the expected result and the actual result.
- **Protocol or product suggestion.** Use it for a change to how AuPM behaves. State the
  motivation, the proposed behavior and the alternatives.
- **Auditor application.** Use it to apply as a package reviewer. The steps are in the
  [onboarding guide](docs/ONBOARDING.md#5-auditor).

For questions about use, read the [onboarding guide](docs/ONBOARDING.md) and the
[HTTP API](docs/API.md) first.

## Report a security problem

Do not open a public issue for a security problem. Use the Security tab of this repository
to open a private vulnerability report.

Never write a recovery phrase or a private key in an issue, a report or a log.
